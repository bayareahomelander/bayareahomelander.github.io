Projects

  1. Open source

    Onyx Grammar-constrained LLM inference engine · Python, Rust, CUDA, MLX

    • Grammar-aware speculative decoding: a Qwen2.5-0.5B draft proposes tokens that a Qwen3-8B FP16 target verifies in one batched pass, with greedy output identical to the target alone. 1.49× aggregate speedup on a 48-request benchmark (RTX 2080 Ti); 2.1–2.4× on JSON, regex, and code.
    • Raised the speedup from 1.17× to 1.49× in one week with hand-written CUDA-graph draft decoding and a deferred draft prefill that cut added time to first token from 637 ms to 0.3 ms.
    • Rust grammar engine (regex DFAs and a JSON Schema state machine via PyO3) applied as cached GPU masks; OpenAI-style FastAPI server with SSE streaming; a separate Apple Silicon (MLX) implementation reached 1.45×.
  2. In progress

    Flint GPT-2 from scratch on hand-written CUDA kernels · C++17, CUDA, inline PTX

    • A CUDA engine that trains GPT-2 (124M) on one consumer GPU and then serves it, with no cuBLAS, cuDNN, or PyTorch at runtime. v0.1 ships December 2026.
    • Tensor-core matrix multiply in inline PTX with deterministic split-K and fused bias, GELU, and residual-add; it already runs at over 80% of cuBLAS on every GPT-2 layer shape.
    • In progress: deterministic flash attention (forward and backward) in 64 KB of shared memory, and FP16 training with loss scaling.
