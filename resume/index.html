ActiveOpen source OnyxGrammar-constrained LLM inference enginePython, Rust, CUDA, MLXgithub.com/bayareahomelander/Onyx
  • Grammar-aware speculative decoding: a Qwen2.5-0.5B draft proposes tokens that a Qwen3-8B FP16 target verifies in one batched pass, with greedy output identical to the target alone. 1.49× aggregate speedup on a 48-request benchmark (RTX 2080 Ti); 2.1–2.4× on JSON, regex, and code.
  • Raised the speedup from 1.17× to 1.49× in one week with hand-written CUDA-graph draft decoding and a deferred draft prefill that cut added time to first token from 637 ms to 0.3 ms.
  • Rust grammar engine (regex DFAs and a JSON Schema state machine via PyO3) applied as cached GPU masks; OpenAI-style FastAPI server with SSE streaming; a separate Apple Silicon (MLX) implementation reached 1.45×.
ActiveOpen source FlintGPT-2 from scratch on hand-written CUDA kernelsC++17, CUDA, inline PTXgithub.com/bayareahomelander/Flint
  • Released v0.1.0, the GEMM: the FP16 tensor-core matrix multiplies a GPT-2 training step needs, with FP32 accumulation, written by hand in CUDA and inline PTX, plus fused bias, GELU, and residual epilogues.
  • On an RTX 2080 Ti at GPT-2 small’s shapes: 82–89% of cuBLAS forward, 86–99% input gradient, 91–108% weight gradient, with fused GELU epilogues faster than cuBLASLt on Turing.
  • Bit-identical results from run to run on one GPU, benchmarked as the median of 10 interleaved rounds against cuBLAS.
